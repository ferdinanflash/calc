# Frosty Fortune Simulator Assets

Folder aset lokal untuk Frosty Fortune Simulator.

Silakan unggah aset gambar simulator ke folder ini. Nama file yang disarankan:

- `frosty-chest-closed.webp` — peti tertutup pada papan 3×3
- `frosty-chest-open.webp` — peti terbuka
- `thorn-of-enigma.webp` — Thorn of Enigma
- `treasure-hunt-chest.webp` — Treasure Hunt Chest
- `mythic-general-hero-shard.webp` — Mythic General Hero Shard
- `lucky-hero-gear-chest.webp` — Lucky Hero Gear Chest
- `fire-crystal.webp` — Fire Crystal
- `gems-of-enigma.webp` — Gems of Enigma
- `snowmobile-skin.webp` — Snowmobile skin
- `mammoth-skin.webp` — Mammoth skin
- `furnace-skin.webp` — Furnace skin

Gunakan format WebP atau PNG dengan latar transparan bila memungkinkan. File di folder ini akan dipanggil menggunakan path relatif dari root website, misalnya `assets/frosty-fortune/frosty-chest-closed.webp`.

Catatan: file README ini menjaga folder tetap ada di Git sebelum gambar diunggah.
